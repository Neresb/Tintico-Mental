¿Cómo recibo el material?

Apenas se confirma el pago, le llega un correo de Hotmart con los archivos para descargar, las veces que quiera. Si no lo ve, revise Promociones o Spam, o escríbanos a tinticomental@gmail.com. Si pagó con Efecty, el correo llega cuando el pago queda confirmado.

¿Necesito impresora?

Ayuda, pero no es obligatoria. Puede imprimir una semana a la vez en una papelería (de 7 a 9 hojas si usa un solo nivel) o usar las fichas en una tablet.

¿La letra se ve bien para personas mayores?

Sí. Las actividades usan letra de 18 puntos o más, con alto contraste y mucho espacio para escribir.

¿Qué diferencia hay entre el nivel Suave y el nivel Reto?

El nivel Suave trae menos elementos y ayudas, como palabras para escoger. El Reto tiene más elementos y ninguna ayuda. Se puede cambiar de nivel cualquier día.

¿Sirve para el Alzheimer o la demencia?

Tintico Mental no es un tratamiento, no diagnostica ni previene enfermedades. Es una actividad para mantener la mente ocupada y entretenida. Si hay un diagnóstico o síntomas que preocupan, consulte a su médico; él puede decirle si estas actividades le sirven como complemento.

¿Cómo puedo pagar?

¿Y si tengo un problema con la compra?
